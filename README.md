# Mythic Dungeons

Mobile-first 2D fantasy RPG project.

## Playable web prototype
Open `index.html` through the stable test link shared in ChatGPT.

## Current core
- Character creation
- 6 classes: Warrior, Ranger, Mage, Assassin, Paladin, Necromancer
- Level / XP system
- Gold and gems
- Core combat stats
- Automatic PvE battle prototype
- Dungeon reward loop
- First boss: Gravefang
- Mobile-first 390x844 reference viewport

## Godot project
Open this repository in Godot 4.x and run `scenes/Main.tscn`.
